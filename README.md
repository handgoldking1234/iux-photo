# IUX Photo · IUX Illust

메뉴 막대 왼쪽 앱 아이콘(IP / IL)으로 이미지 편집기와 벡터 편집기를 오갑니다.

브라우저에서 PSD와 이미지를 바로 열고 고치는 웹 이미지 편집기입니다. 포토샵의 화면 구성과 단축키를 따랐고, 파일은 브라우저 안에서만 처리되어 서버로 올라가지 않습니다.

## 바로 쓰기
- `index.html` 하나로 동작합니다. 더블 클릭으로 열거나 그대로 정적 호스팅(Vercel 등)에 올리면 됩니다.
- PSD 해석기, TIFF 해석기, Pretendard 글꼴이 파일 안에 들어 있어 인터넷 없이도 동작합니다.

## 주요 기능
- **열기**: PSD(레이어·그룹·마스크·클리핑·혼합 모드·문자 레이어), JPG, PNG, WEBP, GIF, BMP, TIF
- **저장**: PSD(레이어 구조 보존), PNG, JPG, WEBP, 레이어별 PNG 묶음(ZIP)
- **도구**: 이동, 선택 윤곽, 올가미, 자동 선택, 자르기, 스포이드, 스팟 복구, 브러시/연필, 복제 도장, 지우개, 그레이디언트/페인트 통, 흐림/선명, 닷지/번/스펀지, 문자, 도형, 손, 돋보기, 자유 변형
- **조정**: 곡선, 레벨, 색조/채도, 명도/대비, 노출, 활기, 색상 균형, 흑백, 포토 필터, 채널 혼합, 색상 검색, 선택 색상, 반전, 포스터화, 한계값, 그레이디언트 맵, 자동 톤/대비/색상
- **필터**: 흐림·선명·노이즈·픽셀화·스타일화·왜곡·렌더·기타·렌즈 교정, Camera Raw 기본 보정
- **문자**: 문자·단락 패널, 웹 폰트 주소로 글꼴 추가 (기본 글꼴 Pretendard)
- **패널**: 레이어, 채널, 히스토리, 속성, 조정, 내비게이터, 히스토그램, 정보, 브러시

## 알아 둘 점
- 레이어 스타일과 조정 레이어는 화면에 그리지 않고 보존만 합니다. PSD로 저장하면 그대로 남습니다.
- 아이폰 HEIC 사진은 브라우저가 읽지 못합니다.

## 소스에서 다시 만들기
```bash
npm install      # ag-psd, utif, pako, pretendard
npm run build    # src/ → index.html (오프라인 단일 파일), dist/artifact.html
```
- `src/style.css`, `src/body.html`, `src/js/*.js`(파일 이름 순서대로 합쳐짐)를 고친 뒤 빌드합니다.

## IUX Illust (벡터 편집기)
- **도구**: 선택·직접 선택, 펜, 고정점 추가/삭제/변환, 문자, 선분, 사각형·둥근 사각형·원형·다각형·별모양, 연필·페인트브러시, 회전·반사·크기 조절, 스포이드, 그레이디언트, 대지, 손, 돋보기
- **편집**: 그룹, 정돈, 잠금·숨기기, 클리핑 마스크, 복합 패스, 패스파인더(합치기·빼기·교차·제외·나누기), 획 윤곽선, 단순화, 변형 반복, 효과(그림자·외부 광선·흐림)
- **패널**: 속성, 레이어, 대지, 색상, 견본, 획, 정렬, 패스파인더, 문자, 그레이디언트
- **파일**: SVG 열기/저장(대지 정보 보존), PNG·JPG 내보내기(대지별·배율), 이미지 가져오기
- **앱 사이 보내기**: 일러스트 → 포토(새 레이어), 포토 → 일러스트(이미지)
- AI·EPS 파일은 열 수 없습니다. 일러스트레이터에서 SVG로 저장해 여세요.
